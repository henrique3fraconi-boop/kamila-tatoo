 # Kamila Rocha Tattoo Uma landing page moderna desenvolvida para a tatuadora Kamila Rocha, com o objetivo de fortalecer sua presença online e facilitar o contato com futuras clientes. Este foi um dos meus primeiros projetos desenvolvidos de forma independente, colocando em prática conhecimentos de HTML, CSS e JavaScript para criar uma interface elegante, responsiva e funcional. Tecnologias utilizadas HTML5, CSS3 e JavaScript. Funcionalidades: página responsiva, design moderno em preto e dourado, navegação suave entre seções, animações ao rolar, FAQ interativo, botão de contato via WhatsApp e integração com Instagram. Estrutura do projeto. kamila-tattoo barra index.html, style.css, script.js e pasta assets barra imagens. Objetivo. Criar uma presença online elegante e profissional para divulgar o trabalho da tatuadora Kamila Rocha, oferecendo uma experiência agradável para futuras clientes. Aprendizados. Durante o desenvolvimento deste projeto, foram praticados estruturação semântica com HTML5, estilização responsiva com CSS3, manipulação básica do DOM com JavaScript e organização de arquivos para um projeto voltado a uma cliente real. Próximas melhorias. Galeria dinâmica de tatuagens, agendamento online, modo escuro e claro, mais animações e melhorias de acessibilidade. Desenvolvedor. Desenvolvido por Henrique Fraconi.
